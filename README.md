**Motorola Sales Dashboard Analysis**

Analyzed Motorola sales data to track performance, identify trends, and generate business insights using Excel and Power BI.

**Overview**

This project focuses on analyzing Motorola mobile sales data to understand sales trends, customer preferences, and regional
performance. The goal is to support data-driven decision-making through interactive dashboards.

**Problem Statement**

Businesses often struggle to track sales performance across regions, time, and product categories. This project aims
to analyze sales data to identify key trends, improve decision-making, and optimize business strategies.

**Dataset**

3836 rows and 14 columns
Includes: Mobile model, sales amount, quantity, transaction details, city, payment method, and date

**Tools & Technologies**

Excel (Data Cleaning & Preprocessing)
Power BI (Dashboard Development & Visualization)

**Methods**

Data Cleaning and Transformation using Excel
Data Modeling and KPI creation in Power BI
Dashboard Development for sales analysis
Trend Analysis and Data Visualization

**Key Insights**

Identified top-performing mobile models and brands
Analyzed monthly and city-wise sales trends
Evaluated impact of payment methods on transactions
Tracked key KPIs like Total Sales, Quantity, and Transactions
